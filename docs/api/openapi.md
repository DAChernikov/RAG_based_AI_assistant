# HTTP API overview

The authoritative OpenAPI 3 schema is generated by FastAPI at `/openapi.json`; Swagger UI is `/docs`. The release smoke validates schema generation.

Public: `GET /health`, `GET /ready`. Browser/token auth: `/v1/auth/login|refresh|logout|me`. User: `/ask`, `/ask/stream`, `/v1/inference-jobs`, job status/events/cancel/retry, conversations, feedback and tenant knowledge-base selection. User-owned API keys: `/v1/api-keys`.

Admin: users, knowledge bases/sources/linking, source versions/refresh/activation/rollback, ingestion runs/events/cancel, indexing runs/events/cancel and index activation/rollback/pin, embedding/runtime health, schedules, retention, model/prompt registry activation, audit browse/export and sanitized runtime.

All list endpoints use `offset` and bounded `limit`. Protected object lookup is tenant-scoped and normally returns 404 for a foreign identifier. Mutations use explicit idempotency headers where duplicate delivery is possible. SSE supports `Last-Event-ID` and a bounded connection lifetime. Error bodies contain sanitized `detail`; credentials and content are not included.
